05 / A FEW ANSWERS

Good questions.
Straight answers.

Does trading in the game use real money?

No. Woowa Chart is a trading game played on real past charts. All trades in the game use virtual funds. It doesn't connect to your exchange account or place real orders. The game license has a separate cost.

Where does the market data come from?

Woowa Chart uses public market data from Binance. No exchange account connection is needed. Historical coverage depends on when each coin was listed and what public data is available.

How many computers can I use?

One license key can activate up to 2 devices. You can deactivate a device and move the license to another device.

Does it work on Mac and Windows?

Yes. Install it as an extension in desktop Chrome on Mac or Windows. It isn't available for Chrome on smartphones.

How do updates work?

Distribution and installation instructions will accompany new releases. Details of the lifetime license's update coverage and policy will be provided before checkout opens.
